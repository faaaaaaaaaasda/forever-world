# ForeverOrigins
Paper 1.20.4+ plugin. 10 origins, each with 10 abilities (5 passive + 5 active) from the start.

- New players pick an origin from a menu (permanent; admins can `/origin reset <player>`)
- `/origin` = view your abilities / select your active ability
- Origin Wand: right-click = cast, left-click = next active ability, sneak + right-click = menu
- Push to GitHub: the Action builds `target/ForeverOrigins.jar` (see the run's Artifacts)
